# Трассировка требований

Каждый идентификатор REQ-4.2.1–REQ-4.2.10 извлечён из исходного SRS (111 требований). Пути реализации относительно `marketplace/`; имена тестов находятся в `tests/`.

«Реализовано локально» означает работающую реализацию и автоматические проверки; «Контракт + адаптер» означает, что нужен действующий внешний сервис и согласование его HTTP/JWT контракта. Это не подтверждение end-to-end интеграции с командным стендом. PostgreSQL/concurrency tests выполняются только с TEST_POSTGRES_URL.
